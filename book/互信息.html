NO.26.tip： 互信息

背景

KL散度为我们提供了一种测量两种分布相似程度的方法。我们应该如何衡量两个随机变量的相互依赖性？我们可以把测量两个随机变量相互依赖性的问题变成关于这两个随机变量分布相似性的问题。这就产生了两个随机变量之间的互信息(Mutual Information, MI)的概念，接下来我们将定义互信息。

定义

随机变量的 X 和 Y 之间的互信息定义如下：

I(X;Y)≜DKL​(p(x,y)∥p(x)p(y))=y∈Y∑​x∈X∑​p(x,y)logp(x)p(y)p(x,y)​(1)

在 X 和/或 Y 表示变量集合的情况下，记作 I(X;Y) 而不是 I(X,Y)。例如，我们可以使用 I(X;Y,Z) 来表示 X 和 (Y,Z) 之间的互信息。对于连续随机变量，我们使用积分来代替求和。

很容易看出，即使对于连续随机变量，互信息也总是非负值，因为：

I(X;Y)=DKL​(p(x,y)∥p(x)p(y))≥0(2)

当且仅当 p(x,y)=p(x)p(y) 时，我们达到边界 0。

解释

互信息是联合和因子边缘分布之间的 KL 散度，这表明如果我们之前将两个变量视为独立的模型 p(x)p(y)，现在更新为对其真实联合密度 p(x,y) 建模的模型，则互信息测量信息增益。

为了进一步理解互信息的含义，我们可以借助于使用联合熵和条件熵的形式重新表达互信息，如下所示：

I(X;Y)=H(X)−H(X∣Y)=H(Y)−H(Y∣X)(3)

因此，我们可以将 X 和 Y 之间的互信息解释为观察 Y 之后，关于 X 的不确定性有所减少；或者通过对称性，将互信息解释为观察 X 之后，关于 Y 的不确定性有所减少。顺便说一句，这个结论提供了另一种证明，即条件从平均程度上会减少熵的值。特别地，我们有 0≤I(X;Y)=H(X)−H(X∣Y)，因此 H(X∣Y)≤H(X)。

我们也可以得到不同的解释。可以证明：

I(X;Y)=H(X,Y)−H(X∣Y)−H(Y∣X)

最后，我们可以证明：

I(X;Y)=H(X)+H(Y)−H(X,Y)(4)

数据处理不等式

假设有一个未知变量 X，我们观察到该变量的一个噪声函数，称之为 Y。如果我们以某种方式处理有噪声的观测结果，以创建一个新的变量 Z，那么直观上应该很明显，我们无法增加关于未知量 X 的信息量。这被称为数据处理不等式。我们现在更正式地陈述这一点，然后加以证明。

定理 假设 X→Y→Z 构成一个马尔可夫链，因此 X⊥Z∣Y。于是，I(X;Y)≥I(X;Z)。

证明

根据互信息的链式法则，我们可以通过两种不同的方式扩展互信息：

I(X;Y,Z)​=I(X;Z)+I(X;Y∣Z)=I(X;Y)+I(X;Z∣Y)​(5)(6)​

由于 X⊥Z∣Y，我们有 I(X;Z∣Y)=0，因此

I(X;Z)+I(X;Y∣Z)=I(X;Y)(7)

由于 I(X;Y∣Z)≥0，我们有 I(X;Y)≥I(X;Z)。同样，我们可以证明 I(Y;Z)≥I(X;Z)。 □

充分统计量

接下来我们介绍数据处理不等式所产生的一个重要结果。假设我们有一个链 θ→X→s(X)。于是

I(θ;s(X))≤I(θ;X)(8)

如果等式成立，那么我们称 s(X) 是数据 X 的充分统计量，该统计量用于推断 θ。在这种情况下，我们可以等价地记作 θ→s(X)→X，因为我们可以通过已知的 s(X) 来重构数据，就像通过已知的 θ 来重构数据一样准确。

充分统计量的一个例子是数据本身，s(X)=X，但这作用不大，因为这个信息根本没有总结数据。因此，我们定义了一个最小充分统计量(minimal sufficient statistic) s(X)，该统计量是充分的，并且不包含关于 θ 的额外信息，因此 s(X) 在不丢失与预测 θ 相关信息的情况下最大限度地压缩数据 X。更正式地，如果对于某个函数 f 和所有充分统计量 s′(X)，s(X)=f(s′(X)) 成立，那么我们称 s 是 X 的最小充分统计量。我们可以将情况总结如下：

θ→s(X)→s′(X)→X(9)

其中，s′(X) 取 s(X) 并向其添加冗余信息，从而创建一对多的映射。

例如，一组 N 个伯努利试验的最小充分统计量被简单地记为 N，并且 N1​=∑n​I[Xn​=1] 是成功的次数。换句话说，我们不需要跟踪正面朝上和反面朝上的整个序列及其顺序，我们只需要跟踪正面朝上的总数和反面朝上的总数。类似地，为了推断具有已知方差的高斯分布的均值，我们只需要知道经验均值和样本数。

我们将指数族视为最小的分布族，因为指数族分布除了对数据的一些统计量进行约束之外，不包含其他信息。因此，用于生成指数族分布的统计数据是充分统计量，这是有道理的。这也暗示了 Pitman-Koopman-Darmois 定理的一个更显著的事实，该定理认为，对于任何域是固定的分布，只有指数族才能随着样本数量的增加而接受足够的有界维数统计信息。

多元互信息

接下来我们介绍几种可以将互信息的概念推广到一组随机变量的方法。

总相关性

定义多变量互信息的最简单方法是使用总相关性(total correlation)或多信息(multi-information)，其定义为：

TC({X1​,⋯,XD​})≜DKL​(p(x)∥d∏​p(xd​))(10)

=x∑​p(x)logd=1∏D​p(xd​)p(x)​=d∑​H(xd​)−H(x)(11)

例如，对于三个变量，该式变成：

TC(X,Y,Z)=H(X)+H(Y)+H(Z)−H(X,Y,Z)(12)

其中，H(X,Y,Z) 是联合熵：

H(X,Y,Z)=−x∑​y∑​z∑​p(x,y,z)logp(x,y,z)(13)

可以证明多信息总是非负的，并且当且仅当 p(x)=∏d​p(xd​) 时多信息为零。然而，这意味着即使只有一对变量相互作用，这个量也是非零的。例如，如果 p(X,Y,Z)=p(X,Y)p(Z)，则总相关性将为非零值，即使不存在三向交互作用(3 way interaction; 又称为三阶交互作用)。

交互信息（协同信息）

条件互信息可用于给出多元互信息(Multivariate Mutual Information, MMI)的归纳定义，如下所示：

I(X1​;⋯;XD​)=I(X1​;⋯;XD−1​)−I(X1​;⋯;XD−1​∣XD​)(14)

这被称为多重互信息(multiple mutual information)或协同信息(coinformation; 又称为共同信息)。这个定义相当于交互信息(interaction information)，只是有一个符号改变。

对于三个变量，多元互信息的定义为：

I(X;Y;Z)​=I(X;Y)−I(X;Y∣Z)=I(X;Z)−I(X;Z∣Y)=I(Y;Z)−I(Y;Z∣X)​(15)(16)(17)​

这可以解释为当以第三个变量为条件时，两对变量之间互信息的变化。请注意，这个量的自变量是对称的。

根据条件互信息的定义，我们有：

I(X;Z∣Y)=I(Z;X,Y)−I(Y;Z)(18)

因此，我们可以将式(16)改写如下：

I(X;Y;Z)=I(X;Z)+I(Y;Z)−I(X,Y;Z)(19)

这表明，多元互信息是我们在分别给定 X 和 Y 的情况下对 Z 学习的程度与在联合给定 X 和 Y 的情况下对 Z 学习的程度之间的差异。

协同和冗余

多元互信息为 I(X;Y;Z)=I(X;Z)+I(Y;Z)−I(X,Y;Z)。我们发现，它可以是正值、零，或者负值。如果由 X 提供的关于 Z 的一些信息也由 Y 提供，那么在 X 和 Y 之间存在一些冗余(redundancy)(相对于 Z)。在这种情况下，$\mathbb{I}(X; Z) + \mathbb{I}(Y; Z) > \mathbb{I}(X, Y; Z)$。相比之下，如果当我们同时提供 X 和 Y 的信息时，我们就会对 Z 有更多的了解，也就是说在 X 和 Y 之间存在一些协同(synergy)(相对于 Z)。在这种情况下，$\mathbb{I}(X; Z) + \mathbb{I}(Y; Z) < \mathbb{I}(X, Y; Z)$，因此多元互信息将为负值。

多元互信息和因果关系

多元互信息的符号可以用于区分不同类型的有向图模型，这些模型有时可以使用因果进行解释。例如，考虑一个形式为 X←Z→Y 的模型，其中 Z 是 X 和 Y 的"原因"。具体示例如下，假设 X 表示下雨的事件，Y 表示天空阴沉的事件，Z 表示天空多云的事件。以共同原因 Z 为条件会使子节点 X 和 Y 变得独立，因为如果我们知道天气多云，同时注意到天空阴沉，这并不会改变我们对是否会下雨的信念。结果 I(X;Y∣Z)≤I(X;Y)，因此 I(X;Y;Z)≥0。

现在考虑一种情况，X→Z←Y，其中 Z 是 X 和 Y 共同作用的效果。在这种情况下，由于解释效应现象(见 4.2.4.2 节)，对 Z 的条件作用使得 X 和 Y 依赖。例如，如果 X 和 Y 是独立的随机比特，Z 是 X 和 Y 的异或操作，则观察到 Z=1 意味着 p(X=Y∣Z=1)=1，因此 X 和 Y 现在是相互依赖的(理论上的信息，而不是因果信息)，即使 X 和 Y 是先验独立的。结果 I(X;Y∣Z)≥I(X;Y)，因此 I(X;Y;Z)≤0。

最后，考虑一个马尔可夫链 X→Y→Z。我们有 I(X;Z∣Y)≤I(X;Z)，所以多元互信息必须是正值。

多元互信息和熵

我们也可以使用熵来表述多元互信息。具体来说，我们已知：

I(X;Y)=H(X)+H(Y)−H(X,Y)(20)

以及：

I(X;Y∣Z)=H(X,Z)+H(Y,Z)−H(Z)−H(X,Y,Z)(21)

因此，我们可以将式(15)改写为如下形式：

I(X;Y;Z)=[H(X)+H(Y)+H(Z)]−[H(X,Y)+H(X,Z)+H(Y,Z)]+H(X,Y,Z)(22)

更普遍地说，我们有：

I(X1​,⋯,XD​)=−T⊆{1,⋯,D}∑​(−1)∣T∣H(T)(23)

对于大小为 1、2 和 3 的集合，其扩展如下：

I1​=H1​(24)

I12​=H1​+H2​−H12​(25)

I123​=H1​+H2​+H3​−H12​−H13​−H23​+H123​(26)

我们可以使用默比乌斯反演公式(Möbius inversion formula)来推导出以下对偶关系。对于变量 S 的集合：

H(S)=−T⊆S∑​(−1)∣T∣I(T)(27)

使用熵的链式法则，我们还可以导出三向多元互信息的表达式，如下所示：

I(X;Y;Z)=H(Z)−H(Z∣X)−H(Z∣Y)+H(Z∣X,Y)(28)

源与流

互信息的变分上下界

对于计算困难的分布，我们将讨论使用其变分近似来计算互信息上界和下界的方法。这对表征学习十分有用。

变分上界

假设联合 p(x,y) 难以计算，但我们可以从 p(x) 中采样并计算条件分布 p(y∣x)。此外，假设使用 q(y) 来近似 p(y)。然后我们就可以计算互信息的上界，如下所示：

I(x;y)​=Ep(x,y)​[logp(y)q(y)p(y∣x)q(y)​]=Ep(x,y)​[logq(y)p(y∣x)​]−DKL​(p(y)∥q(y))≤Ep(x)​[Ep(y∣x)​[logq(y)p(y∣x)​]]=Ep(x)​[DKL​(p(y∣x)∥q(y))]​(29)(30)(31)(32)​

如果 q(y)=p(y)，那么上下界都具有紧密性。

进一步解释如下：我们有 I(Y;X)=H(Y)−H(Y∣X)，假设已知 p(y∣x)，所以可以很好地计算 H(Y∣X)。虽然不知道 H(Y) 的值，但我们可以使用一些模型 q(y) 来确定其上界。我们的模型永远不会比 p(y) 本身(KL 散度的非负性)做得更好，熵估计误差太大，因此我们的互信息估计将是一个上界。

BA下界

假设联合概率 p(x,y) 难以计算，但我们可以评估 p(x) 的值。此外，假设我们使用 q(x∣y) 来近似计算 p(x∣y)。然后我们可以在互信息上导出以下变分下界：

I(x;y)​=Ep(x,y)​[logp(x)p(x∣y)​]=Ep(x,y)​[logp(x)q(x∣y)​]+Ep(y)​[DKL​(p(x∣y)∥q(x∣y))]≥Ep(x,y)​[logp(x)q(x∣y)​]=Ep(x,y)​[logq(x∣y)]+h(x)​(33)(34)(35)​

其中，h(x) 是 x 的微分熵。这被称为 BA 下界，以作者 Barber 和 Agakov 的名字命名。

NWJ下界

BA 下界需要一个可处理的归一化分布 q(x∣y)，我们可以逐点计算该归一化分布。如果我们采用一种巧妙的方式重新参数化这个分布，就可以生成一个不需要归一化分布的下界，记作：

q(x∣y)=Z(y)p(x)ef(x,y)​(36)

其中，Z(y)=Ep(x)​[ef(x,y)] 是归一化常数或配分函数。将其代入上述 BA 下界，我们可以得到：

Ep(x,y)​[logp(x)Z(y)p(x)ef(x,y)​]​=Ep(x,y)​[f(x,y)]−Ep(y)​[logZ(y)]=Ep(x,y)​[f(x,y)]−Ep(y)​[logEp(x)​[ef(x,y)]]≜IDV​(X;Y)​(37)(38)(39)​

这是 Donsker-Varadhan 下界(DV 下界)。

我们可以通过使用以下事实来构造一个更易于处理的版本。使用下式，对数函数可以由一条直线构成上界：

logx≤ax​+loga−1(40)

如果设置 a=e，那么我们得到：

I(X;Y)≥Ep(x,y)​[f(x,y)]−e−1Ep(y)​Z(y)≜INWJ​(X;Y)(41)

这被称为 NWJ 下界(以作者 Nguyen、Wainwright 和 Jordan 的名字命名)，或者 f 生成式对抗性网络 KL 散度，或者 MINE-f 分数。

InfoNCE下界

如果转而探索对上述 DV 下界的多样本扩展，我们可以生成以下下界：

INCE​​=E[K1​i=1∑K​logK1​∑j=1K​ef(xi​,yj​)ef(xi​,yi​)​]=logK−E​K1​i=1∑K​log​1+j=i∑​ef(xi​,yj​)−f(xi​,yi​)​​​(42)(43)​

其中，期望是来自联合分布 p(X,Y) 的成对样本。式(43)中的量被称为 InfoNCE 估计。

其直观理解是，互信息是联合分布 p(x,y) 和边缘分布乘积 p(x)p(y) 之间的散度。换句话说，互信息是对联合分布采样对与独立采样 x 和 y 之间差异的测量。式(43)中的 InfoNCE 界通过尝试对模型进行训练来区分这两种情况，并提供了真实互信息的下界。

尽管这是一个有效的下界，但如果互信息很大，我们可能需要使用较大批次规模的 K 来估计互信息，因为 INCE​≤logK。
